HostFlip

Toggle the current tab between development and production.

Keyboard shortcut optional

Current: not set

Opens the browser shortcuts page. Default suggestion: Alt+Shift+V.

How it works

Clicking the toolbar icon opens this settings page. To switch environments, press your keyboard shortcut. If the current page is on your development domain it jumps to production; if it is on your production domain it jumps back to development. The path, query string and hash are always preserved. If the current host matches neither domain, HostFlip shows a message on the page instead of navigating. Configuration is optional — the defaults (localhost:4200 and github.com) apply until you change them.
