# Support

## Usage questions

Start with the [README](README.md), especially the installation,
configuration, and privacy sections. HostFlip is an unpacked Manifest V3
extension and currently has no build or package-install step.

## Bug reports

Open a GitHub issue and include:

- Chrome or Edge and its version.
- HostFlip version.
- The configured host shapes, with private domains replaced by examples.
- Steps to reproduce and the expected and actual behavior.
- Console or extension error messages, if available.

Never include passwords, access tokens, private URLs, or personal browsing
history.

## Feature requests

Explain the problem the feature would solve, who would benefit, and any
alternative workflow you use today. Small, focused proposals are easiest to
review.
